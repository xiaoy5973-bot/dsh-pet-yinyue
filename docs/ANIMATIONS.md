# 动画清单

三套动画全部为 **VP9 + Alpha** 编码的 `.webm`，1920×1080，24fps，透明背景。
人物在画面中的位置已统一（脚底基线一致、水平居中），切换动画时不会跳位。

| 文件 | 帧数 | 时长 | 播放方式 | 用途 |
|---|---|---|---|---|
| `待机.webm` | 239 | 9.96 s | 循环 | 日常站立待机 |
| `回应-挥手.webm` | 79 | 3.29 s | 单次 | 点击宠物的回应动作 |
| `工作中.webm` | 92 | 3.83 s | 循环 | AI 干活时的状态动画 |

## 配置里的对应关系

```jsonc
"animations": {
  "idle":   ["待机"],              // 待机循环
  "clicks": ["回应-挥手"],          // 点击回应
  "events": {
    "workStatus": [                // 六档工作状态，索引即档位
      "工作中", "工作中", "工作中",   // 0 思考 / 1 工作 / 2 整理 —— 循环
      "待机",                      // 3 等待 —— 循环
      "回应-挥手",                  // 4 成功 —— 播一遍
      "待机"                        // 5 出错 —— 播一遍
    ],
    "whisper": ["待机"],           // 碎碎念时的动作
    "balance": ["待机"]            // 余额气泡时的动作
  }
}
```

`turn` / `drag` / `moves` / `categories` 都是空池 —— 银月只做了这三个动作，
所以不会转向、不会被拖拽播放专属动画、也不会随机走动。需要的话可以自己补素材。

## 关于「工作中」的循环

源素材里有两次视线移动，直接首尾相接会看出跳帧。当前版本是把三段区间
（`34–89` + `90–108` + `16–33`）拼接，并在第二个接缝处做了 5 帧交叉溶解，
让循环接缝的帧差落在自然相邻帧的范围内。

## 想自己加动画？

把新的 `.webm`（VP9 Alpha）放进 `pet/yinyue-animation/`，然后在
`pet/yinyue-config.json` 的对应池子里写上文件名（不含扩展名），刷新 DSH 页面即可。

素材规范：

- 容器：WebM，视频编码 VP9，带 alpha 通道
- 建议尺寸：宽 1920、高 1080（插件会按 `size` 缩放）
- 建议帧率：24fps
- **脚底基线与水平中心要和其他动画一致**，否则切换时会「跳一下」

> macOS Safari 需要 `.mov`（HEVC with Alpha）。dsh-pet 会自动优先找
> `pet/yinyue-animation/mov/` 下的同名文件，找不到再退回 `.webm`。
